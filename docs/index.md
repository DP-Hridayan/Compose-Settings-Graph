# Compose Settings Graph

A declarative, type-safe DSL for building beautiful, perfectly reactive settings screens in Jetpack Compose.

## Features
- **God-Tier DSL**: Build entire settings screens using a clean, readable Kotlin DSL.
- **Strictly Reactive**: Zero unnecessary recompositions. Theme, haptics, and values update instantly.
- **Fully Customizable**: Built-in slots, custom dividers, and pure Compose interoperability.

## Installation

Add the dependency to your `build.gradle.kts` file:

```kotlin
dependencies {
    implementation("io.github.dp-hridayan:compose-settings-graph:{{ library_version() }}")
}
```
